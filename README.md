CAR MARKET SYSTEM
this project designed for car sales company
you can add customer,saler,car,images and make sales



database bağlanmak için : mysqli kurduktan sonra src klasorü altındaki db.properties belgesine kendi mysql şifrenizi girin


db connection hatası çözümü:
https://repo1.maven.org/maven2/com/mysql/mysql-connector-j/8.3.0/ bu siteden mysql-connector-j-8.3.0.jar dosyasını yükle
compilerda projenin kütüphanesine bu dosyayı ekle


**çalıştırmak için compiler üzerinden CarMarketSystem/src/ui/MainMenu.java dosyasını çalıştırmanız yeterli
